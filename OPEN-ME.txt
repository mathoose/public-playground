Do not run python from your home folder. That is why localhost:8080 says 404.

Close that Terminal window.

To customize the frame, in Chrome paste:

  https://cdn.jsdelivr.net/gh/mathoose/public-playground@cursor/bubble-frame-finder-7f53/bubble-frame/index.html

Or in Finder double-click  Open Bubble Frame.html
(that file is not blocked by Apple the way the .command file is).

If you already saw “Start Bubble Frame.command Not Opened”:
  1. Click Done  — not Move to Trash
  2. Right-click Start Bubble Frame.command → Open → Open
     or Apple menu → System Settings → Privacy & Security → Open Anyway

To print the default 4×6, skip the app: open the bubble-frame folder and
drag these into your slicer:
  bubble-frame-4x6in-frame.stl
  bubble-frame-4x6in-back.stl
  bubble-frame-4x6in-stand.stl
