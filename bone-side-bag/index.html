Bone chain

Each link is a bone: a closed eye, a narrow shaft, and a hook. The hook snaps around the next eye. The gate is narrower than the eye, so flex it on — PETG forgives more than stiff PLA. Add links for a longer shoulder strap. Two clasps close the strap onto the eyelets.

Print — Snapmaker U1

In Snapmaker Orca (or Orca with U1 machine profile): typical workflow for a PLA cup with supports that snap off cleanly — same idea as MakerWorld bone bags, with sizes from this designer. Full multimaterial guide: PLA + PETG on U1.

Filament roles (PLA model)

  • Model / body: PLA (bone white or your color)
  • Support base: PLA (default support material)
  • Support / raft interface only: PETG — enable Avoid interface filament for base so PETG touches only the model interface, not the whole support tree

Support settings (body only)

  • Style: Tree (Hybrid); if interface gaps misbehave, try Strong Trees
  • Top Z distance: 0 mm (critical on U1 multimaterial interface)
  • Top interface layers: 2–3 · spacing 0 · pattern rectilinear
  • Independent support layer height: on
  • On build plate only: on (keeps support scars off the bag outer surface)

PETG interface filament profile (clone your PETG slot)

  • Lower max volumetric speed for interface passes (~1.5–3 mm³/s)
  • Optional +10–15 °C on interface only
  • Flow ratio 1.0 for support/interface extrusion
  • Match XY shrinkage to your PLA profile (Snapmaker forum / wiki tuning)

Prime / wipe tower: PLA base + PETG interface needs a tower — use a slower wipe tower speed if you see weak bonds or color bleed.

Parts & orientation (download STLs separately; do not slice the joint 3MF for multimaterial unless you split objects yourself)

  • Body STL — side bag cup or phone cage (same export, depends on Piece mode). Opening up on the bed; supports under ribs / overhangs only
  • Chain STL — lay links flat; usually no supports (minimal if a hook overhang flags)
  • Clasps STL — flat; no supports

Entire bag in PETG? Reverse roles: PETG for the model, PLA as support interface only (same 0 mm top Z distance and interface layer recipe).

Three parts, one assembly. The 3MF keeps the body, the chain, and both clasps in place. The STLs are those same parts, separate. Print the body opening up, PLA or PETG, 0.2 mm layers, 3 walls, 15% infill. The chain and clasps lie flat and need no supports. Snap each hook onto the next eye, then snap a clasp through each eyelet and the end of the chain. If the chain row is longer than the bed, split to objects and arrange the links.
