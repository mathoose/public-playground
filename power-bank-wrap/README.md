# Power bank wrap

Live **slide-on cord-wrap sleeve** for Mattheus’s mint **SYJSHUANGXI SYJ-F37F** (143 × 68 × 16 mm). Cord wraps **around the sleeve band** (the 68×16 cross-section), never over the USB end. **Four elastic omega clips** — **two on the top face, two on the bottom face**, spaced apart along the sleeve — with **flared filleted roots** so they don’t snap off.

## What it is

An open-ended band the bank **slides into**. USB ports and LEDs stay out.

- **Taper** (default **0.4 mm per side**) so it grips
- **Two C-channels around the 68×16 perimeter**, default **17 mm** wide
- **Four elastic omega clips** on the top and bottom faces (2 each), flared roots, mouth ~58% of the cord

## Print (Snapmaker Luban / PETG)

1. Stand it on the **tight end**, hole pointing up. **No supports.**
2. **PETG**, 0.4 mm nozzle, **0.2 mm** layers, **4 walls**, 20–25% infill.
3. Slide the **10+ end in first**. Wind the cord around the band; snap each end into a top or bottom clip.

Default outer size is **72.0 × 87.2 × 38.6 mm** — fits A150 / A250 / A350.
