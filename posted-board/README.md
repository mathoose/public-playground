# Posted board

Phone-friendly kanban. Imports always land in **Incoming**. Drag a card (or use **Move**) into High / Medium / Low / Waiting / Done.

Data stays on this device (`localStorage`). This playground repo is public — do not treat the board as a private quality system of record.

## Open

Open `posted-board/index.html` in a browser (or the Netlify URL if you point a site at this folder).
