# public-playground

Scratch repo for small experiments.

- [`aruba-packing/`](aruba-packing/) — packing list + wardrobe grid
- [`postit-wall-clip/`](postit-wall-clip/) — reprint of a wall Post-it holder clip
- [`bubble-frame/`](bubble-frame/) — customizable 3D-printed bubble picture frame (STL). In Finder, open that folder: double-click `Start Bubble Frame.command`, or print the `.stl` files already inside.
