# public-playground

Scratch repo for small experiments.

## Cloud notes

Talk from your phone in a Cloud Agent. Each voice dump is saved under [`cloud-notes/`](cloud-notes/README.md) as `YYYY-MM-DD/HHMM-what-you-talked-about.md`.

On the computer: pull this repo, attach `@cloud-notes` or `@cloud-notes/INBOX.md`, and tell Cursor to work the inbox.
