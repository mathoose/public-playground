# Cloud notes folder

This directory is the voice inbox. When you `@` these files:

1. Read `INBOX.md` first. Work **Open** top to bottom.
2. For each note, do the suggested actions (or record what blocked them).
3. Mark the note `status: done` and move its inbox row to **Done**.

New captures: follow the repo rule `.cursor/rules/cloud-notes.mdc` and copy `_template.md`.
