# Squiggle frame

A closed wavy tube around a photo. Each visit picks a new squiggle. The tube thickness is a slider. Photo width and height are yours. Snap clips on the back pinch the border. Wall hang is a flat rear. Stand mode adds two holes and a pair of pegs.
