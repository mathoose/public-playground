# Squiggle frame

A thick rounded squiggle around a photo. Randomize draws a new one. The tube thickness is a slider. Photo width and height are yours. Snap clips on the back pinch the border. The back has a rectangular slot. A separate carrot leg slides into that slot and widens so it stays. Sliders set the leg angle and width. Stand test exports one small joint, asks for the settings, engraves those numbers on the piece, and keeps them in the download log so they can be loaded again. Wall hang is a flat rear. Stand mode also adds two holes and a pair of pegs. The header saves a named pattern in this browser.
