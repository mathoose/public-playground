# Squiggle frame

A thick rounded squiggle around a photo. Randomize draws a new one. The tube thickness is a slider. Photo width and height are yours. Snap clips on the back pinch the border. Wall hang is a flat rear. Stand mode adds two holes and a pair of pegs. The header saves a named pattern in this browser.
