# Baroque frame

Editor for the miniature baroque frame. Width and height change how big the picture is. The moulding stays the same width: corners and the center ornaments keep their shape, and only the quieter stretch of each side gets longer or shorter. Frame thickness is separate. It scales the border and the depth together.

The sculpture is Mari3d’s miniature baroque frame. Print flat, face up.

Default outer size is about **78.2 × 100 mm**, moulding about **16.2 mm**, depth about **6.0 mm**.
