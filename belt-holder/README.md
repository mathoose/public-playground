# Belt holder

Closet holder that plugs into an upright’s holes. **Belt clip** is an open C a rolled belt sits in. **Square bin** is the same mount with side walls and an open top.

Defaults are 5 mm pins on 32 mm centers (a common closet pitch). Hole spacing, pin diameter, pin length, width, cradle diameter or bin depth, and wall thickness are sliders.

Print pins down, opening up. One STL for the mode you are looking at.
